# FICSIT Flow — визуальный планировщик фабрик Satisfactory

Интерактивный редактор производственных цепочек уровня Satisfactory Tools / FICSIT Planner:
бесконечный холст (React Flow), автопостроение цепочек, мгновенный пересчёт всей сети,
электричество, Somersloops, Power Shards, анализ узких мест, оптимизация рецептов
и совместная работа в реальном времени.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
```

### Игра по локальной сети / Radmin VPN

```bash
npm run lan
```

Скрипт поднимает Vite на всех интерфейсах **и** локальный сервер комнат (WebSocket, порт 1234),
затем печатает ссылку вида `http://192.168.x.x:5173` — её открывает друг.
Дальше: **👥 Комната → Создать**, друг вводит код (или открывает ссылку-приглашение
`http://ваш-IP:5173/#room=КОД`). Вся синхронизация идёт через ваш компьютер, интернет не нужен.

## Архитектура

```
src/
  engine/     — Calculation Engine: чистая TS-библиотека без UI-зависимостей
    database.ts   индексы по базе игры
    solver.ts     итеративный решатель потоков (циклы, дефициты, распределение)
    autobuild.ts  автопостроение цепочек до сырья (байпродукты, андерклок, Somersloops)
    optimizer.ts  выбор рецептов под цель (энергия / здания / ресурсы / sink-очки)
    advisor.ts    рекомендации и «Модернизация фабрики»
  data/       — game-data.json: единая БД игры (генерируется скриптом)
  worker/     — пересчёт больших графов в Web Worker
  collab/     — Yjs CRDT: комнаты, роли, чат, журнал, курсоры (WebRTC + локальный WS)
  store/      — zustand-стор: undo/redo, автосохранение, проекты, share-ссылки
  ui/         — Visual Editor: холст, узлы, панели, диалоги
```

## База игровых данных

`npm run data` (флаг `--icons` докачивает иконки) пересобирает `src/data/game-data.json` из
`data/source/docs-parsed.json` — комьюнити-парса официального `CommunityResources/Docs.json`
(Satisfactory 1.0/1.1): 177 предметов, 276 машинных рецептов (включая 110 альтернативных),
все производственные здания, добытчики, генераторы, конвейеры Mk.1–6 (60–1200/мин),
трубы Mk.1–2 (300/600 м³/мин), sink-очки, энергия топлива.
Обновление игры = обновление одного JSON, логика не меняется.

Механики, которых нет в Docs.json, заданы в `scripts/build-data.mjs` (блок SUPPLEMENT)
по официальной вики: слоты Somersloop по зданиям, геотермальная мощность по чистоте,
Alien Power Augmenter, доступность ресурсов на карте (веса оптимизатора).

Формулы: разгон 1–250 % (`clock^1.321929` для энергии производственных зданий, генераторы
линейно), Power Shards +50 %/шт, Production Amplifier — выход ×(1+слоты/макс), энергия ×(множитель)².

## Тесты и производительность

```bash
npx tsx scripts/engine-test.ts   # проверка против известных игровых значений
npx tsx scripts/perf.ts          # бенчмарк решателя
```

2400 узлов / 3000 линий решаются за ~230 мс в фоновом воркере; цепочка Ballistic Warp Drive — 11 мс.
